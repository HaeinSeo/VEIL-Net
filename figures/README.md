# Figures

The project author supplied these three PNG files for the public repository.
They are included without cropping, recoloring, or changes to their contents.

| File | Content |
| --- | --- |
| [veil-mascot.png](veil-mascot.png) | VEIL-Net project mascot |
| [scene-completion.png](scene-completion.png) | Scene RGB, scene point cloud, partial target, and completion examples |
| [qualitative-comparison.png](qualitative-comparison.png) | Input, Fusion, PoinTr, SnowflakeNet, VEIL-Net, and ground-truth columns |

The scene figure includes preprocessing outside the completion network.
The comparison labels are preserved as supplied; in particular, the image says
SnowflakeNet, while the main README's quantitative comparison uses SnowflakeNet FT.
Run identities for these illustrations have not been attached to the source files.
